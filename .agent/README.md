# Pacote de especificações

O diretório `docs/specs/` contém 25 arquivos SPEC, um para cada card identificado no quadro Trello fornecido.

As especificações foram elaboradas com base nas descrições e critérios de aceite dos cards e nos documentos extraídos de `docs.rar`. Os status refletem a posição dos cards no quadro em 09/11/2026 e não representam uma verificação independente do código-fonte.

Consulte `docs/specs/README.md` para índice, fontes e observações de consistência.
