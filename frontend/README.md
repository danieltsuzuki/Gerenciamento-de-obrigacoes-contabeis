# Frontend — Gerenciador de Obrigações Contábeis

Módulo de frontend em Flutter para o sistema de Gerenciamento de Obrigações Contábeis.

## Estrutura Prevista

- Arquitetura: *Feature-First / Clean Architecture*
- Gerenciamento de Estado: MobX ou Cubit/Bloc
- Comunicação com Backend: Camada de integração REST com consumo da API (`/api/**`)
- Plataformas: Web, Desktop e Mobile (Android/iOS)

Consulte a especificação [SPEC-013](../.agent/docs/specs/13-criar-estrutura-e-navegacao-do-flutter.spec.md) e o documento de arquitetura [docs/arquitetura.md](../docs/arquitetura.md) para detalhes.
